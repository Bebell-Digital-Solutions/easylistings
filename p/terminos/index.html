6. Período de Prueba Gratuito

EasyListings ofrece un período de prueba de catorce (14) días naturales para la suscripción mensual.

El período de prueba comienza cuando el Cliente publica por primera vez un sitio web mediante su cuenta.

La tarifa de activación no se considera parte del período de prueba y se cobra independientemente de este.

Durante los catorce (14) días:

  1. El Cliente podrá utilizar las funcionalidades incluidas en el plan seleccionado.
  2. No se cobrará la tarifa mensual de suscripción.
  3. El Cliente deberá contar con una cuenta PayPal para autorizar el mecanismo de pago recurrente.
  4. La fecha de finalización del período de prueba se determinará a partir de la fecha de publicación inicial del sitio web.

Una vez finalizado el período de prueba, comenzará automáticamente la suscripción mensual y se realizará el primer cobro correspondiente al plan seleccionado, salvo que el Cliente haya cancelado previamente.

El Cliente autoriza expresamente este mecanismo de facturación al aceptar la suscripción y completar la autorización de pago correspondiente.

EasyListings deberá informar claramente el precio, la periodicidad y la fecha del primer cobro antes de que el Cliente confirme la contratación.
