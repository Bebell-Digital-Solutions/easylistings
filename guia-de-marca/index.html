⚡ Cómo usar estos logos en tus proyectos

Los archivos de esta página son placeholders generados en vivo. Sustitúyelos por tus archivos finales guardándolos en /assets/ y actualizando la ruta en el snippet de abajo. 

<!-- Logo a color -->
<img src="assets/easylistings-color.svg" alt="EasyListings" width="150" height="32">

<!-- Logo blanco (fondos oscuros) -->
<img src="assets/easylistings-white.svg" alt="EasyListings" width="150" height="32">

<!-- Logo negro (impresión) -->
<img src="assets/easylistings-black.svg" alt="EasyListings" width="150" height="32">

<!-- Icono / favicon -->
<link rel="icon" href="assets/easylistings-icon.svg">

<!-- Fallback WebP con PNG de respaldo -->
<picture>
  <source srcset="assets/easylistings-color.webp" type="image/webp">
  <img src="assets/easylistings-color.png" alt="EasyListings" width="150" height="32">
</picture>

05 · Tokens

Variables CSS globales

Pegalas en el :root de cualquier página nueva y todos los componentes funcionan igual.

:root{
  /* Brand */
  --primary:#DF1783;
  --primary-hover:#C21170;
  --primary-soft:#FDEEFA;

  /* Accents */
  --secondary:#2D3748;
  --accent:#40B39A;
  --accent-deep:#0F6E5C;

  /* Surfaces */
  --bg:#FAF8F5;
  --bg-alt:#F2EFE9;
  --card-bg:#FFFFFF;

  /* Text */
  --text:#2D3748;
  --text-strong:#0E0E10;
  --muted:#5C5C63;
  --muted-2:#718096;

  /* Lines & depth */
  --border:#E5E1DA;
  --border-2:#E2E8F0;
  --shadow-sm:0 1px 3px rgba(45,55,72,.06), 0 1px 2px rgba(45,55,72,.04);
  --shadow-lg:0 20px 40px -12px rgba(45,55,72,.18);

  /* Shape */
  --radius-card:20px;
  --radius-btn:12px;
  --gradient-accent:linear-gradient(90deg,transparent 0%,#DF1783 50%,transparent 100%);
}
/* Scrollbar de marca */
::-webkit-scrollbar{width:8px;height:8px}
::-webkit-scrollbar-track{background:#F2EFE9}
::-webkit-scrollbar-thumb{background:#DF1783;border-radius:8px}

/* Selección de texto */
::selection{background:rgba(223,23,131,.22);color:#0E0E10}

/* Reveal on scroll */
.reveal{
  opacity:0;transform:translateY(28px);
  transition:opacity .7s cubic-bezier(.22,.61,.36,1),
             transform .7s cubic-bezier(.22,.61,.36,1);
}
.reveal.in{opacity:1;transform:none}

/* Respeto por reduced motion */
@media (prefers-reduced-motion: reduce){
  .reveal{opacity:1;transform:none;transition:none}
  *{animation:none!important;transition-duration:.01ms!important}
}
06 · Motion

Micro-interacciones

Movimiento sutil, siempre al servicio del contenido. Todo se desactiva con prefers-reduced-motion.

/* Hover lift de tarjetas */
.feature-card{transition:.28s}
.feature-card:hover{
  transform:translateY(-6px);
  box-shadow:var(--shadow-lg);
  border-color:var(--primary);
}
.feature-card:hover .card-icon{transform:scale(1.08)}
.feature-card:hover .explore-link span{transform:translateX(4px)}
/* Botón primario con glow */
.primary-btn{transition:transform .2s, background .2s, box-shadow .2s}
.primary-btn:hover{
  background:var(--primary-hover);
  transform:translateY(-3px);
  box-shadow:0 12px 24px -8px rgba(223,23,131,.55);
}

/* Underline animado del nav */
.nav-links a::after{
  transform:scaleX(0);transform-origin:left;
  transition:transform .25s ease;
}
.nav-links a:hover::after{transform:scaleX(1)}
